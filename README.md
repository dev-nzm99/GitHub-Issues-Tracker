### 1️.What is the difference between `var`, `let`, and `const`?

- **var**: Function-scoped variable that can be redeclared and reassigned.  
- **let**: Block-scoped variable that can be reassigned but cannot be redeclared in the same scope.  
- **const**: Block-scoped variable that cannot be reassigned or redeclared after initialization.

##

### 2️.What is the spread operator (`...`)?

The **spread operator (`...`)** expands elements of an iterable (such as arrays or objects) into individual elements, commonly used for copying, merging, or passing values.

##

### 3️.What is the difference between `map()`, `filter()`, and `forEach()`?

- **map()**: Transforms each element and returns a new array.  
- **filter()**: Returns a new array containing elements that satisfy a condition.  
- **forEach()**: Executes a function for each element but does not return a new array.

##

### 4.What is an arrow function?

An **arrow function** is a concise syntax for writing functions introduced in ES6, which does not have its own `this` binding and is commonly used for short callback functions.

##

### 5.What are template literals?

**Template literals** are a string syntax in JavaScript that allows embedded expressions and multi-line strings using backticks.
